# ✈️ SKYBOOK — Flight Reservation System

**A web-based flight reservation demonstration built using Python, Flask, HTML, CSS, and JavaScript.**

SKYBOOK is a college mini-project that demonstrates how searching and sorting algorithms can be applied to a flight reservation system. Users can explore available demo flights, search for routes, compare fares, and interact with a simulated booking interface.

## 🌟 Features

- **Flight Search:** Search for flights using source and destination cities.
- **One-Way & Round-Trip:** Select the type of journey.
- **Flight Listings:** View available demo flights with airline names, fares, seat availability, and stops.
- **Sorting & Filtering:** Explore flight options using searching and sorting concepts.
- **Booking Interface:** Interact with a demonstration booking flow.
- **Responsive Design:** A user-friendly interface for different screen sizes.
- **DSA Demonstration:** Connect flight-search functionality with data structure and algorithm concepts.

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or later
- pip
- Git

### 1. Clone the repository

```bash
git clone https://github.com/pranavxe/SKYBOOK.git
cd SKYBOOK
```

### 2. Create a virtual environment

**Windows PowerShell:**

```powershell
python -m venv .venv
```

### 3. Activate the virtual environment

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install Flask

```powershell
python -m pip install Flask
```

### 5. Run the application

```powershell
python app.py
```

### 6. Open SKYBOOK

Visit the following address in your browser:

http://127.0.0.1:5000

## 🧠 DSA Concepts

This project demonstrates how searching and sorting techniques can support flight discovery and comparison.

- **Searching:** Find flights that match the selected route.
- **Sorting:** Organize flight results based on criteria such as fare.
- **Filtering:** Narrow down available options based on user selections.

The specific algorithms used depend on the implementation in the source code.

## ⚠️ Disclaimer

SKYBOOK is an educational demonstration project. Flight records and fares are sample data. It does not provide real-time airline availability, actual ticket reservations, or real payment processing.

## 🎯 Project Objective

The objective of SKYBOOK is to apply data structure and algorithm concepts to a practical web application while learning backend development, frontend interaction, and integration between Python and web technologies.
